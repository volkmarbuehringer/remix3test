# Lookup: Airbnb Do's and Don'ts

**Core Idea**: Quick reference rules for implementing Airbnb-styled designs—ensures consistency with brand guidelines.

## Do ✅

- Use `#222222` (warm near-black) for text—never `#000000`
- Apply Rausch Red (`#ff385c`) only for primary CTAs and brand moments
- Use Airbnb Cereal VF at weight 500–700—the warm weight range is intentional
- Apply three-layer card shadow for all elevated surfaces
- Use generous border-radius: 8px for buttons, 20px for cards, 50% for controls
- Use photography as primary visual content—listings are image-first
- Apply negative letter-spacing (-0.18px to -0.44px) on headings for intimacy
- Use circular (50%) buttons for carousel/navigation controls
- Use `--palette-*` token system for colors

## Don't ❌

- Don't use pure black (`#000000`) for text—always `#222222` (warm)
- Don't apply Rausch Red to backgrounds or large surfaces—it's accent only
- Don't use thin font weights (300, 400) for headings—500 minimum
- Don't use heavy shadows (>0.1 opacity as primary layer)—keep warm and graduated
- Don't use sharp corners (0-4px) on cards—the generous rounding (20px+) is core
- Don't introduce additional brand colors beyond Rausch/Luxe/Plus system
- Don't override the palette token system—use `--palette-*` consistently
- Don't use bright/harsh colors—the design is warm and minimal

**Quick Checklist**:
- [ ] Text is #222222, not #000000
- [ ] Red used for CTAs only, not backgrounds
- [ ] Headings use 500+ weight
- [ ] Cards have 20px+ radius
- [ ] Shadows have 3 layers
- [ ] Colors use --palette-* tokens
