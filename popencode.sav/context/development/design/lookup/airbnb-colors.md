# Lookup: Airbnb Color Tokens

**Core Idea**: Systematic color palette with clear roles—brand accent, premium tiers, text hierarchy, and surface colors.

**Color Roles**:

### Primary Brand
| Token | Hex | Use |
|-------|-----|-----|
| `--palette-bg-primary-core` | #ff385c | Rausch Red—CTAs, brand accent |
| `--palette-bg-tertiary-core` | #e00b41 | Deep Rausch—pressed state |
| `--palette-text-primary-error` | #c13515 | Error Red—error text on light |
| `--palette-text-secondary-error-hover` | #b32505 | Error Dark—error hover |

### Premium Tiers
| Token | Hex | Use |
|-------|-----|-----|
| `--palette-bg-primary-luxe` | #460479 | Luxe Purple—Airbnb Luxe tier |
| `--palette-bg-primary-plus` | #92174d | Plus Magenta—Airbnb Plus tier |

### Text Scale
| Token | Hex | Use |
|-------|-----|-----|
| `--palette-text-primary` | #222222 | Near Black—primary text (warm!) |
| `--palette-text-focused` | #3f3f3f | Focused Gray—focused state |
| `--palette-text-secondary` | #6a6a6a | Secondary Gray—descriptions |
| `--palette-text-disabled` | rgba(0,0,0,0.24) | Disabled state |
| `--palette-text-link-disabled` | #929292 | Disabled links |

### Interactive & Surface
| Token | Hex | Use |
|-------|-----|-----|
| `--palette-text-legal` | #428bff | Legal Blue—legal links |
| `--palette-border` | #c1c1c1 | Border Gray—dividers |
| `--palette-surface-secondary` | #f2f2f2 | Light Surface—nav buttons |
| `--palette-bg-surface` | #ffffff | Pure White—page background |

**Quick Reference**:
- Background: #ffffff (pure white)
- Text: #222222 (warm near-black, never #000000)
- Brand accent: #ff385c (Rausch Red—accent only, not bg)
- Secondary text: #6a6a6a
